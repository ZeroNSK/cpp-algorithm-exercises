# Алгоритмы и структуры данных на C++

**Прежнее название репозитория:** `3Sem2Lab`.

Набор самостоятельных задач на C++: LFU-кэш, поиск уникальной подстроки, гистограммы, деревья поиска, множества и стековые алгоритмы.

**Примерный период реализации:** ноябрь 2025. Период указан по истории Git и отражает основную работу над проектом.

## Содержимое

Каждый `.cpp` — отдельное упражнение. Среди них `lfu_cache.cpp`, `substring_unique.cpp`, `histogram.cpp`, `bst_branches.cpp` и `stack_game.cpp`.

## Сборка отдельной задачи

```bash
clang++ -std=c++17 -O2 lfu_cache.cpp -o lfu_cache
./lfu_cache
```

Формат входных данных определяется выбранной задачей.
